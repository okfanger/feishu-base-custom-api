选输入列 → 写提示词 → 批量生成文本/图片/视频/爬取写回表格

① 对话模型（存本机 ~/.feishu-base-agent/models.yaml）

打开下方「模型库」添加供应商与 API Key。

① 模型配置（存在本机浏览器，不上传）

② 任务配置

文本模式：走后端 pi-py Agent。选了📎输入图=下载后发给视觉模型看图写文。
图片模式：浏览器直连生图 API。选了📎输入图=图生图(保产品)，没选=文生图。
爬取模式：从 URL 列（或提示词里的链接）抓取页面，可选写回文本列和/或附件列。中文页优先用 pruning 过滤器。
🎬 视频模式独立配置。方舟官方没开浏览器跨域，API 地址填你服务器上的透传代理（形如 http://127.0.0.1:8000/api/ark/v3）；选中转站格式则直接填中转地址。⚠️ Seedance 2.0 约1元/秒（15秒≈15元/条），先用「只跑当前光标所在行」试效果再批量。
也可以在提示词里写完整 URL，或用【列名】拼出地址。
高级参数（对齐 crawl4ai CrawlerRunConfig）

③ 模型库

配置写到本机 ~/.feishu-base-agent/models.yaml，Key 可用 ${ENV_VAR}。协议目前支持 openai-completions / anthropic-messages。
